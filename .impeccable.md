## Design Context

### Users
Demo and portfolio viewers who open the app once to see what it can do.

### Brand personality
Plain, competent, quiet. The tools carry the demo, not decoration.

### Aesthetic direction
Keep the existing layout and the app's bslib font. One accent color: app blue `#007bc2` (`app/styles/colors.R`). Light theme.
Anti-references: gradient cards, colored side-stripe borders, one color per section, drop shadows, uppercase buttons, empty fixed-height cards.

### Design principles
1. One accent color, used for actions only.
2. Cards size to their content.
3. Neutral headings; hierarchy from size and weight, not color.
4. Same structure as other pages, so the homepage matches the app.
